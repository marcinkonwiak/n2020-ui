## Usage

Render `Toaster` once, in the root layout of the application. It reads the theme from `next-themes`.

```tsx
import { toast } from "sonner";
import { Toaster } from "@/components/ui/sonner";
```

```tsx
<Toaster />
```

Call `toast` from anywhere to show a message.

```tsx
toast("Deploy started");
```
